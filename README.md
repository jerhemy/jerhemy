## 👋 About Me

I'm a US-based Software Engineer focused on **C#/.NET, full-stack development, enterprise architecture, backend systems, and distributed applications**. I enjoy designing scalable APIs, building reliable integrations, and bringing ambitious ideas to life.

Beyond traditional software, I experiment with **local LLMs, AI/ML, generative AI, automation, GPU computing, and immersive AR/VR/XR experiences**.

## ⚡ What I Build

**🏗️ Enterprise & Backend Engineering**  
Scalable services, .NET applications, REST APIs, distributed systems, and system integrations.

**🧠 AI, Machine Learning & Automation**  
Local LLMs, RAG pipelines, LoRA fine-tuning, generative media, and intelligent agents.

**🎮 Interactive & Immersive Experiences**  
Unity, real-time applications, game development, and AR/VR/XR experiences.

**🐳 Infrastructure & Developer Tooling**  
Docker, self-hosted services, databases, development workflows, and automation tools.
